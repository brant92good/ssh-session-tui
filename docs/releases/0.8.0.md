SSH Sessions 0.8 adds a Files start screen. Run `ssh-sessions files`, choose a
server, or expand its named remote paths and open a project directory directly.
It uses the existing machine catalog and optional compiled SSH Files companion.
Browsing does not connect; selecting a route with R uses it once without changing
this device's saved choice. Failed connections never trigger automatic fallback.

Named paths live beside the catalog in `<catalog filename>.files.json` and join
explicit Git sync. Saves reject stale catalog or path revisions. Sync includes
only these two metadata files; unrelated staged changes and device preferences
stay outside that commit. Incoming metadata is validated before a fast-forward.

Windows ConPTY tests cover offline entry, literal path arguments, scrolling long
route lists, companion handoff, error acknowledgement and competing preset edits.
The release pipeline builds/tests five platform targets and checks the actual
HTTPS installers. macOS remains beta until physical desktop use is qualified.

Assets are compiled Rust programs with checksums and license notices. Normal
installation requires no Python, Git or Rust compiler. OpenSSH is needed to
connect; Git is optional for explicit catalog sync. SSH Files is installed
separately or bundled by Terminal Workspace.
